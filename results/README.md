# Reference experiment outputs

These files record the real GSE48684 to GSE68060 benchmark run. Start with summary.csv, predictions.csv, protocol_frozen.json and manifest.json.

Use the root README commands to generate separate reproduced_results outputs. Figures distributed with the paper can be rebuilt with analyze_results.py. The manifest is preserved from the full original run; figure binaries and its packaging-only upload guide are intentionally absent from this repository.
